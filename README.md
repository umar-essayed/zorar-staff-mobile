# 📱 تطبيق زرار كود — الإدارة والمساعدين والمدرسين (Zorar Staff & Teacher Pro)

تطبيق الموبايل الموحد لمنظومة **زرار كود (Zorar Code / EduZorar Pro)** لإدارة السناتر التعليمية، المجموعات، الحضور اللحظي بالباركود، ونقاط البيع المحمولة.

## ✨ أبرز الميزات:
- **محطة الحضور الفائقة (Sub-10ms Scanner):** كاميرا لمسح كروت الطلاب، تنبيهات صوتية واهتزازات، ودعم الحصص الاستثنائية.
- **نقطة البيع المحمولة (Mobile POS):** سداد الاشتراكات والملازم، طباعة بلوتوث حرارية (58mm/80mm)، ومشاركة إيصال رسمي عبر واتساب.
- **لوحة المعلم وغرفة الحصة الحية:** رصد درجات التسميع والواجبات والملاحظات السلوكية لحظياً مع كشف حساب أرباح المعلم.
- **الهوية المخصصة (White-Label):** تخصيص اسم وشعار وألوان السنتر، مع تغيير أيقونة التطبيق على شاشة الهاتف ديناميكياً.
- **الجداول الضخمة:** جدول بيانات ذكي تفاعلي (`DataTable2`) بعمود ثابت وسرعة بناء فائقة.

## 🚀 البناء السحابي (Cloud CI/CD):
يتم بناء ملفات الـ APK تلقائياً عبر GitHub Actions بمجرد الدفع (Push) على الفرع الرئيسي وتوفيرها مباشرة في قسم [Releases](../../releases).
